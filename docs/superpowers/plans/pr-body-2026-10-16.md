## Execution differences and observations

- Task 1.4's supplied regression passed before the fix (3 peak rounds, error
  -0.026 LU, -1.0000 dBTP). Task 2.9's supplied hum regression also passed before
  scaling; empty-input, high-pass and interval failures were reproduced.
- Corpus randomness consumes samples, so the same seed is not rate-invariant.
  Owner-approved 44.1 kHz expectations allow one false positive; native precision
  remains >=0.75. Worst measured speech/SNR margins are **0.86/0.16 dB**.
- MSVC requires `numeric_limits<double>::infinity()` rather than constant
  `1.0 / 0.0`. Nested JSON closing also needed per-frame inline state.
- `SF_FORMAT_OPUS` is an enum, not a preprocessor macro; availability uses
  libsndfile support plus `sf_format_check`.
- Task 4.1's fixture had no required 600 ms speech run (maximum 400 ms), and its
  pause window preceded the 300 ms hold + 700 ms release settling. Following
  the owner's instruction to continue autonomously, the unit test uses controlled
  speech/pause intervals and settled windows; engine defaults and numeric
  tolerances were retained. End-to-end cases exercise real corpus segmentation.
- Worker lifecycle guards, exception handling and stale-result checks were
  added for the preview/candidate jobs. Export invalidation includes delivery
  targets and music changes. The global cancellation chip now says "Annullato".
- Supplied graphic layouts needed explicit navigation/transport padding, sparse
  VU labels and a waveform label gutter to avoid overlaps and clipped text.
- `WixUI_InstallDir` already provides `ARPNOMODIFY`; the duplicate definition
  fails linking and was omitted. The runtime-copy loop excludes stale
  `opengl32sw.dll` explicitly. Windows display name is now "Podcast Sanity".
- On this machine Windows Installer exposes ARP under HKLM with current-user
  MSI registration under HKCU. Verification checks both uninstall roots and
  the current-user product registration rather than assuming HKCU ARP only.
- The export stale-master hint may show `0 Hz` for automatic sample rate;
  this cosmetic observation remains.
